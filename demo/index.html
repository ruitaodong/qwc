Whole-slide images in QWC2

The same tissue microarray from the PLISM dataset, scanned on two Aperio scanners and served as web maps by QGIS Server through an OpenSlide plugin for GDAL.

What you’re looking at

Each map is one slide: about 50 tissue cores on a single glass slide, roughly 8 gigapixels per scan. Open both and compare the colours: the AT2 renders stain far more saturated than the GT450. The colours shown are the scanners’ raw RGB values. The AT2 file embeds an ICC colour profile that isn’t applied here, so part of the difference you see is exactly what colour management would correct.

The two scans cover slightly different areas at different pixel sizes, so their maps aren’t aligned with each other. Map units are slide pixels: the coordinate display shows pixel positions, and the scale bar’s “metres” are pixels.
